# Derek Shirley | Decision Science, Growth, and Data Systems

**[View the live site](https://www.derekdevs.com)**

Static professional portfolio for case studies and decision-science work.

## Stack

- Astro
- MDX content collections
- TypeScript
- Plain CSS

Pages are static. Case studies, work listings, and experience live in content collections.

## Getting started

Node.js 22+ is recommended.

```sh
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

```sh
npm run build
npm run preview
```
